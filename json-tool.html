How to validate JSON

JSON requires double quotes around property names and string values. Commas separate items but should not trail the final item. Objects use curly braces and arrays use square brackets. Values can be strings, numbers, booleans, null, objects, or arrays.

Valid JSON example

{
  "id": 101,
  "active": true,
  "tags": ["qa", "api"],
  "owner": null
}

Common JSON syntax errors

  • Using single quotes instead of double quotes.
  • Leaving a trailing comma after the last property or array item.
  • Forgetting a closing brace, bracket, or quotation mark.
  • Using comments, undefined, or NaN, which are not standard JSON values.

Frequently asked questions

Does formatting change the data?

Formatting changes whitespace only. Minifying removes unnecessary whitespace; both actions preserve the parsed JSON value.

Can this validate an API response against a schema?

No. It checks JSON syntax and formats or minifies the value; it does not validate against JSON Schema or an API contract.

Is my JSON uploaded?

No. Processing happens in your browser. Still avoid pasting credentials, personal information, or confidential production payloads.
